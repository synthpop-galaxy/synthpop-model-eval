# synthpop-model-eval
Code used by [Huston et al. (2026)](https://ui.adsabs.harvard.edu/abs/2026arXiv260312219H/abstract) to compare SynthPop to various observational data sets. 

This code was written by and for the SynthPop dev team and not documented in detail, but others are welcome to apply the code to their own SynthPop applications.
